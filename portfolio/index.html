問い合わせフォームの自動返信と担当者への通知

Googleフォームに回答が届いたら、お客様に受付メールを送り、担当者にも内容を知らせます。回答はスプレッドシートに自動でたまります。

// フォーム送信時に動く（スプレッドシートのトリガーに設定）
const NOTIFY_TO = 'owner@example.com'; // 担当者のアドレス

function onFormSubmit(e) {
  const v = e.namedValues; // { 質問: [回答] }
  const name = (v['お名前'] || ['お客様'])[0];
  const to = (v['メールアドレス'] || [''])[0].trim();
  const body = Object.keys(v).map(k => `${k}：${v[k][0]}`).join('\n');

  if (/^[^@\s]+@[^@\s]+$/.test(to)) {
    MailApp.sendEmail(to, '【受付完了】お問い合わせありがとうございます',
      `${name} 様\n\n以下の内容で受け付けました。\n\n${body}\n\n2営業日以内にご連絡します。`);
  }
  MailApp.sendEmail(NOTIFY_TO, `新しい問い合わせ：${name} 様`, body);
}

実際の案件では、質問の項目名・文面・通知先（メール、Slack、LINEなど）をご要望に合わせます。
